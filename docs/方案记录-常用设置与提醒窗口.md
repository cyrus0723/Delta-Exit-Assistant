# 三角洲下机助手：常用设置与提醒窗口方案

状态：讨论稿，尚未实施

## 目标

让第一次使用的人能快速完成“再玩多久”或“玩到几点”的设置，并在检测到结算画面时看到更醒目的中文提醒。

## 交互结构

采用“控制窗口 + 托盘入口”的混合方式：

- 托盘保留后台运行、快速设置和退出能力。
- 一个紧凑控制窗口承载常用设置、当前计时状态和高级设置。
- 关闭控制窗口只隐藏到托盘，不默认退出程序。
- 游戏全屏时不主动弹出控制窗口；真正触发提醒时再显示独立的置顶提醒窗口。

托盘右键菜单第一栏放置两个常用动作：

1. `再玩 X 小时`
2. `玩到 X 点下`

设置完成后自动开始计时与检测。原来的“启动检测”可以保留为状态动作或备用入口，但不再要求普通用户单独点击它。

## 两种计时模式

两种模式共用同一套“预计单局时长”计算和检测闸门：

- `玩到 X 点下`：目标时刻是当天的绝对时间。
- `再玩 X 小时`：目标时刻是设置瞬间加上 X 小时。

两者的实际提醒开启时刻都为：

`目标时刻 - 当前游戏预计单局时长`

这样可以在用户预计要停止的时间点附近完成最后一局提醒，而不是在目标时刻之后才提醒。需要明确展示当前状态，例如“预计 01:30 开始提醒，目标 02:00 停止”。

## 提醒内容

- 默认标题和正文改成面向用户的中文，不显示 `score`、模板 ID 等调试字段。
- 用户可分别编辑“提示标题”和“提示正文”。
- 触发提醒时显示应用自己的大字置顶窗口，并保留声音/系统通知作为可选方式。
- 提醒窗口必须有明确的关闭按钮；关闭提醒不应意外停止后台检测，另提供“停止本次提醒计划”动作。

系统 Toast 的字号由 Windows 控制，不能作为放大字体的唯一实现，因此大字体应由 Tk 自有窗口承担。

## 设置分层

普通设置：

- 当前游戏
- 再玩 X 小时
- 玩到 X 点下
- 当前游戏预计单局时长
- 提示文案
- 弹窗、响铃或两者

高级设置：

- 匹配灵敏度（原 threshold）
- 防止重复提醒的回落幅度（原 hysteresis）
- 两次提醒最短间隔（原 cooldown）
- 检测频率（原 scan interval）

校准与维护：

- 调整结算画面检测区域（原 ROI 调整）
- 查看当前检测区域（原预览 ROI）
- 录入结算画面（原抓取模板）
- 测试提醒（原发送测试通知）

## 取舍与风险

控制窗口会增加窗口生命周期、线程通信、全屏遮挡和“关闭/最小化”语义的处理成本。默认使用“关闭即隐藏到托盘”可以保留后台工具的轻量特性，同时让首次设置和状态查看更易理解。
