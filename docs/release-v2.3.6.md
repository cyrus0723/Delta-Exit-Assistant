# 三角洲下机助手 v2.3.6

- 主窗口改为 Windows 11 风格的浅色布局，使用左侧导航与蓝色主按钮。
- 功能分为“开始”“提醒设置”“模板与识别”“高级设置”四页。
- 开始页合并检测状态与游戏选择，默认窗口下一屏展示提醒设置，无需滚动；较小窗口保留滚动，避免内容被截断。
- 加大模块卡片圆角，内容无需滚动时自动隐藏滚动条。
- 保留现有检测、提醒、配置与托盘行为。

## 下载

- 安装版：`Delta-Exit-Assistant-Setup-2.3.6.exe`。
- 便携版：`Delta-Exit-Assistant-Portable-2.3.6.zip`，完整解压后运行“启动助手.cmd”。
- 用户设置与自定义模板仍保存在 `%LOCALAPPDATA%\DeltaExitAssistant`。

## 验证

- 21 项单元测试通过。
- 已检查四个页面在默认与较小窗口尺寸下的布局，并确认默认开始页无需滚动。
- 实际游戏结算识别与长时间运行未在本次 UI 更新中重新验证。
