# 三角洲下机助手 v2.3.8

- 预计单局时长移到当前游戏下方，支持按游戏独立保存。
- 修复侧栏图标偶尔不显示的问题，统一图标尺寸与文字对齐。
- 提醒文案增加问号帮助浮层，保留编辑内容，点击其它位置即可关闭。
- 首页提醒时机支持整行空白区域点击选择。
- 修复修改指定时间后直接开始检测仍使用旧时间的问题；无效时间会阻止启动。

## 下载

- 安装版：Delta-Exit-Assistant-Setup-2.3.8.exe。
- 便携版：Delta-Exit-Assistant-Portable-2.3.8.zip，完整解压后运行“启动助手.cmd”。
- 设置与自定义模板保存在 %LOCALAPPDATA%\DeltaExitAssistant。
