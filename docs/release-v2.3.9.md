# 三角洲下机助手 v2.3.9

- 新增打开助手后自动开始检测的选项，沿用保存的游戏和提醒设置。
- 新增当前 Windows 用户登录时启动助手的选项，可与自动检测分别设置。
- 调整两个选项的勾选样式。

## 下载

- 安装版：Delta-Exit-Assistant-Setup-2.3.9.exe。
- 便携版：Delta-Exit-Assistant-Portable-2.3.9.zip，完整解压后运行“启动助手.cmd”。
- 设置、自定义模板与提示音保存在 %LOCALAPPDATA%\DeltaExitAssistant。
- 移动便携版后，需要关闭并重新开启开机自启动以更新路径。
