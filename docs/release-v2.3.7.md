# 三角洲下机助手 v2.3.7

- 开始页采用更大的按钮圆角，选中的提醒时机使用浅蓝色高亮，时间说明集中显示。
- 时间与时长增加上下调节按钮，也支持键盘上下键。
- 提醒弹窗统一蓝白配色，优化内容布局和屏幕内定位。
- 检测状态定期刷新，避免开始检测后界面状态未更新；刷新不会覆盖正在输入的时间。
- 压缩页面留白，四个页面在默认窗口尺寸下均可一屏展示，小窗口保留滚动。

## 下载

- 安装版：`Delta-Exit-Assistant-Setup-2.3.7.exe`。
- 便携版：`Delta-Exit-Assistant-Portable-2.3.7.zip`，完整解压后运行“启动助手.cmd”。
- 用户设置与自定义模板仍保存在 `%LOCALAPPDATA%\DeltaExitAssistant`。

## 验证

- 23 项单元测试通过，包含启停状态刷新与保留未保存输入的回归检查。
- 已检查默认窗口和较小窗口布局，以及预览中的时间调节和启停操作。
- 实际游戏结算识别与长时间运行未在本次 UI 更新中重新验证。
